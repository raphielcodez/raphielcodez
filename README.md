## `featured_projects` 📂

### 📈 [Adani Stock Analysis](https://github.com/raphielcodez/adani-stock-analysis)

Analyzed historical stock data to explore company performance, returns, volatility, and market behavior around the January 2023 Hindenburg Research event.

**What it explores:** data preparation, company comparisons, daily and cumulative returns, volatility, and visual reporting.

**Tools:** Python, SQL, data analysis, visualization.

### 🌐 CIC-Darknet Traffic Analysis

Explored network traffic classifications and patterns, including darknet traffic share, category distributions, and differences across network types and time periods. The dashboard work focuses on making traffic patterns easier to investigate.

**What it explores:** traffic summaries, category comparisons, time trends, protocols, and flow characteristics.

**Tools:** Tableau, data analysis, dashboard design.

> This project is in progress. A repository link will be added when it is published.

### 👥 [HR Employee Attrition Analysis](https://github.com/raphielcodez/ibm-hr-employee-attrition-excel)

An Excel portfolio project using IBM's fictional HR employee attrition dataset to examine workforce composition and patterns associated with employee exits.

**What it explores:** data preparation, readable analysis fields, formulas, PivotTables, KPIs, and dashboard reporting.

**Tools:** Microsoft Excel.
